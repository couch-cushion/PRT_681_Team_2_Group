# Tasks Console App — Developer Week 1

C# console application using SQLite and Microsoft.Data.Sqlite.

## Features
- Create a task
- View saved tasks
- Update title and completion status
- Delete a task by ID
- Validate menu input and task IDs

## Run
Open this folder in VS Code and run:

    dotnet run

The application creates tasks.db beside the running executable.
The database file is excluded from Git.

## Manual verification
Test Create, Read, Update, Delete, invalid IDs, and persistence
by closing and reopening the application.

## Learning
C# models, .NET console applications, SQL CRUD, parameterized
commands, SQLite connections, and persistent storage.
